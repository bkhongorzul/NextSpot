# NextSpot 디자인 명세 (Pleos Connect, 다크)

Claude Code에게: 이 문서는 `ui/DemoScreen.kt`와 시작 화면(`RoleScreen`)을 다시 만들 때의 기준이다.
**로직(`DemoEngine.kt`, `DepartureDetector.kt`, `SpotRepository.kt`)은 건드리지 않는다.** 화면에 보이는 값만 바꾼다.
같은 폴더의 `reference/*.dc.html`은 이 디자인을 HTML로 만든 원본 시안이다. 값이 헷갈리면 그 파일의 인라인 style을 정답으로 본다.

---

## 0. 원칙

- Pleos Connect **다크 모드** 토큰만 쓴다 (출처: Pleos design assets / display guide 2.1.5 피그마).
- 버튼은 기본적으로 **무채색**(Pleos 순정 방식). 메인 색 노랑은 **운전자가 실제로 누를 핵심 버튼 1개, 찾는 차, 경로, 현재 단계**에만.
- 운전 중엔 음성으로만 묻고 답한다. 화면은 1~2초 안에 읽혀야 한다 → 한 화면에 "지도 + 지금" 두 가지만 크게.
- 모서리는 거의 네모: 큰 면 12, 버튼·카드 8, 작은 표시 4.
- 테두리로 영역을 나누지 않는다. 바탕색 차이로만 나눈다. 카드 안에 카드 금지.
- 이모지 금지. 아이콘은 아래 9절의 선 아이콘(24 viewBox, stroke 2~2.4)만.
- 언어 전환 버튼 없음. 언어는 차(시스템) 설정을 따른다 → `Strings.kt`에서 `Locale`로 고른다.

## 1. 크기 단위

시안은 Pleos 표준 화면 **2560×1440** 기준 px로 그렸다. Pleos 토큰(`size_sp/level*`)은 Connect-S에서 피그마 px 값을 그대로 sp/dp로 쓰므로, **아래 숫자는 그대로 dp/sp로 옮긴다.**
화면이 다르면(예: 1920×1080 Connect-L) 앱 창 크기 비율로 스케일만 맞춘다 (`Theme.kt`의 `NsDims.scale`).

## 8. 움직임 (중요: 속도를 일정하게)

easing: `cubic-bezier(0.4, 0, 0.3, 1)` (Compose: `CubicBezierEasing(0.4f, 0f, 0.3f, 1f)`). **시간은 거리에 맞춰 각각 다르게.** 고정 0.9초 금지.

찾는 차 (Phase별 목표 [x, y, 회전, 초]): IDLE (120,620,90°, 0초=즉시) · SEARCHING (210,620,90°, 2.5) · LIKELY (280,620,90°, 2.4) · OFFER (340,620,90°, 1.6) · RESERVED (460,620,90°, 2.6) · CONFIRMED (560,620,90°, 2.4) · WITHDRAWN (920,620,90°, 3.2).

나가는 차 (CONFIRMED가 되면 3구간을 차례로): (672,168,0°) → 후진 (672,370,0°) 1.3초 → 회전해 위 차로 (830,420,90°) 1.1초 → 빠져나가며 사라짐 (1180,420,90°, 불투명 0) 1.9초.

찾는 차 주차 (TAKEN이 되면 2구간): (560,620,90°) → 칸 앞 (672,420,0°) 1.6초 → 칸 안 (672,168,0°) 1.6초.

처음부터/재생 시작 시 차들은 **즉시** 제자리로 (거꾸로 미끄러지지 않게).

자동 재생 순서와 간격(앞 단계 후 ms): 찾기 800 → 문 2500 → 내비 1200 → 제안 2800 → "네" 3000 → 브레이크 3000 → 주차 4000.
취소 흐름: … "네" 3000 → 출발 취소 3000. (`DemoEngine.playScenario`의 delay 값을 이것으로 바꾼다. 수동 모드에서 제안은 '곧 빔' 1.2초 뒤 자동.)

## 11. 기존 코드와 연결

- `DemoEngine`의 상태(`searching, door, nav, brake, spot.status, asking, accepted, parked, credits, log`)와 `phase`를 그대로 읽는다.
- `log`의 who 값: "Car A" → 나가는 차, "Car B" → 찾는 차, "클라우드"/"시스템" → NextSpot. 기록 문장은 `Strings.log`의 키로 바꿔 쓰거나, 엔진의 `add()` 문구를 `Strings.kt`로 옮긴다 (이모지 제거).
- `SignalPanel.kt`의 칩 줄, `EventLog`의 상시 표시, `SdkInfo`는 시연 화면에서 뺀다 (기록은 "기록 전체 보기"로, 신호는 "차 신호 직접 보내기"로).
- 차 이미지: `res/drawable/car_parked.png`, `car_leaving.png`, `car_mine.png` (Pleos 디스플레이 가이드 피그마의 주차장·탑뷰 렌더에서 잘라낸 것).
